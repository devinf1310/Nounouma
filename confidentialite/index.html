4. Rédaction de documents par intelligence artificielle

Certaines fonctionnalités de Nounouma — le projet d'accueil et les observations du développement — rédigent un document à partir des informations que vous avez saisies. Cette rédaction est effectuée par un prestataire technique d'intelligence artificielle agissant pour notre compte, en qualité de sous-traitant au sens de l'article 28 du RGPD.

Ce qui est transmis

Le contenu que vous avez renseigné et qui figurera dans le document : votre présentation professionnelle, la description de votre accueil, et, pour un projet personnalisé, les informations relatives à l'enfant concerné — prénom et nom, âge, habitudes, besoins particuliers, allergies, contacts d'urgence avec leur lien de parenté et leur numéro de téléphone — ainsi que les coordonnées de l'assistante maternelle et du parent référent. Ces informations vous ont été confiées par les parents pour l'accueil de leur enfant et figurent, par nature, dans le document remis.

À qui

Trois prestataires sont appelés dans cet ordre, jusqu'à ce que l'un réponde : OpenAI, puis Groq, puis Hugging Face. Un même document peut donc être traité par l'un ou par l'autre, selon la disponibilité du service au moment de la demande. Le traitement peut avoir lieu en dehors de l'Union européenne ; ces transferts s'appuient sur les clauses contractuelles types de la Commission européenne.

Pour quoi faire

Uniquement produire le document demandé. Les prestataires n'utilisent pas ces contenus pour entraîner leurs modèles, conformément à leurs conditions d'utilisation professionnelles.

Combien de temps

Le document produit est conservé dans votre espace jusqu'à ce que vous le supprimiez : chaque document peut être supprimé depuis la liste de vos projets. Le contenu transmis n'est pas conservé par Nounouma au-delà de la rédaction.

Ce que vous pouvez faire

Dans l'application, la rédaction assistée est le seul moyen de produire ces documents : demander un projet d'accueil ou une observation implique la transmission décrite ci-dessus. Vous restez libre de ne pas utiliser ces fonctionnalités, et vous relisez le document avant tout partage.

Pour toute question ou demande relative à vos données, écrivez à support@nounouma.fr.

5. Information des parents

Les informations relatives à votre enfant que vous confiez à l'assistante maternelle via Nounouma — prénom et nom, âge, habitudes, besoins particuliers, allergies, contacts d'urgence — peuvent être traitées dans le cadre décrit au point 4, lorsque l'assistante maternelle demande la rédaction d'un projet d'accueil personnalisé ou d'une observation du développement. Vous disposez sur ces données des mêmes droits qu'au point 3.

6. Suppression de votre compte

Vous pouvez supprimer votre compte vous-même, depuis l'application. Le détail de ce qui est effacé, de ce qui est conservé et du délai dont vous disposez pour revenir sur votre décision figure sur la page Suppression de compte.

Contact : support@nounouma.fr
